# Projeto do TCC para compartilhar com o orientador

- `TCC_Eduardo_Hoppen.zip`: fontes para importar em um editor LaTeX online.
- `projeto_latex/`: os mesmos arquivos, descompactados.
- `Relatorio_Final.pdf`: PDF de referência da versão enviada.
- `validacao.json`: resultado da compilação local do pacote isolado.

## Compartilhar pelo Overleaf

1. Acesse sua conta no Overleaf.
2. Crie um projeto usando **New Project → Upload Project** e selecione
   `TCC_Eduardo_Hoppen.zip`.
3. Nas configurações, selecione `Relatorio_Final.tex` como documento principal
   e **XeLaTeX** como compilador.
4. Recompile e confira o resultado com o PDF de referência.
5. Use **Share/Compartilhar** para convidar o professor pelo e-mail ou fornecer
   um link com a permissão desejada. Prefira convite restrito.

O ZIP também pode ser usado em outros editores que aceitem projetos LaTeX
com arquivos próprios de classe e compilação XeLaTeX/BibTeX. A importação
em Texpage ou Prism não foi testada. Criar esta pasta não publica o artigo
nem cria automaticamente um projeto ou link de compartilhamento.

## Conteúdo e cuidados

O pacote contém somente o artigo atual, classe institucional ativa, logotipo,
bibliografia, diagramas, capturas utilizadas e resultados agregados necessários
à compilação. Os arquivos copiados preservam os bytes dos originais.

Não inclui credenciais, código da aplicação, planilhas individuais do
questionário, registros internos de auditoria ou versões antigas do artigo.
As capturas e os resultados agregados que já integram o artigo permanecem.

O template ativo foi mantido, sem substituição. O pacote não foi baixado do
Moodle nesta preparação. Se o professor indicar um arquivo diferente, compare
as versões antes de substituir a classe.

Esta pasta é uma cópia de envio, não sincronizada automaticamente com
`docs/artigo_final/`. Depois de editar online, mantenha uma versão de referência
e evite alterações paralelas divergentes.
